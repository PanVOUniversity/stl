# STL Skip List Container - Документация

Это документация для STL-контейнера "Список с пропусками" (Skip List).

## Доступ к документации

Документация доступна по адресу: [https://your-username.github.io/stl](https://your-username.github.io/stl)

## Структура документации

- `index.html` - главная страница документации
- `classes.html` - список классов
- `functions.html` - список функций
- `files.html` - список файлов
- `search.html` - страница поиска

## Настройка GitHub Pages

1. Перейдите в настройки репозитория на GitHub
2. Найдите раздел "Pages" в боковом меню
3. В разделе "Source" выберите "Deploy from a branch"
4. Выберите ветку `work` и папку `/docs`
5. Сохраните настройки

После этого GitHub автоматически развернет ваш сайт.
